# 🗓️ Timetable - Rainmeter 动态课表皮肤

这是一个使用 Rainmeter 和 Lua 脚本编写的桌面课表模板。它会自动判断今天是星期几，并在桌面上竖向显示当天的课程。

## ⚠️ 修改前必读（极其重要）

1. **编码警告**：如果你修改了 `Timetable.lua`，保存时**必须**在“另存为”界面，将底部的编码选择为 **Unicode**（即 UTF-16 LE）。如果存为 UTF-8，桌面会什么都显示不出来！
2. **不要按回车**：在填写课表时，**千万不要直接敲键盘的回车键**。必须用 `\n` 这个符号来代表换行，否则程序会报错。

---

## 📥 软件下载（Rainmeter）

本皮肤需要搭配 **Rainmeter**（雨滴桌面）才能运行。如果你还没安装：

1. 前往 Rainmeter 官方网站：https://www.rainmeter.net/ 
2. 点击页面上的 **Download** 按钮，下载最新的安装包（.exe）。
3. 双击下载好的文件，一路点击“Next（下一步）”即可完成安装。

---

## 🚀 安装方法

1. 下载本仓库的代码。
2. 右键点击电脑右下角托盘的 Rainmeter 图标 -> 选择 **“皮肤”** -> **“打开皮肤目录”**。
3. 在打开的文件夹里，新建一个名为 `Timetable` 的文件夹。
4. 将本仓库的 `Timetable.ini` 和 `Timetable.lua` 放进去。
5. 刷新 Rainmeter，在管理器中找到并加载 `Timetable.ini`。

## 🛠️ 教程一：如何填写你的专属课表？

用记事本打开 `Timetable.lua`，找到最上面 `days` 区域。
你现在的代码里是占位符，**请直接把你原本的那一行代码删掉，换成下面这种格式**：

`days["周一"] = "第1节 语文\n第2节 数学\n第3节 英语\n第4节 自习"`
`days["周二"] = "第1节 物理\n第2节 化学\n第3节 体育"`
`days["周三"] = "第1节 历史\n第2节 地理"`

*(提示：如果某天没有课，可以写成 `days["周六"] = "今天没课"`。如果某节课是空的，直接写 `第3节 \n` 即可。以此类推，写满周一到周六。)*

---

## 🧠 教程二：如何改为“周末双休”（周六不上课）？

原版逻辑中，周六有课，周日显示“晚修”。如果你的学校周六日全休，请按以下两步修改：

**第一步：修改 `Timetable.lua`**
在文件的最下方，找到 `Update()` 函数里的这一句：`if wd == 1 then`
把这一行**直接替换为**：`if wd == 1 or wd == 7 then`

然后，往下找两行，找到：`return "周日 晚修"`
把它**直接替换为**：`return "周末休息"`

**第二步：删除周六数据**
在最上面的 `days` 区域，把 `days["周六"] = "..."` 这一整行直接删掉。

## 🎨 教程三：如何修改背景与颜色？

用记事本打开 `Timetable.ini`，找到 `[Variables]` 区域，以下参数可自行调整：

- `FontFace=Microsoft YaHei` ：字体，需确保电脑里有这个字体
- `FontSize=14` ：课程正文的大小
- `TitleSize=18` ：标题的大小
- `BgWidth=260` ：背景板宽度（课程名长就调大）
- `BgHeight=310` ：背景板高度（课少就调小，课多就调大）
- `BgAlpha=60` ：背景板透明度（0全透明，255不透明）

---

## 🪄 教程四：如何去掉标题里的“课程表”三个字？

如果你觉得“周一 课程表”太啰嗦，只想显示“周一”：

1. 打开 `Timetable.lua`，找到最后倒数第二行：`return day .. " 课程表\n" .. content`
   将其改为：`return day .. "\n" .. content`

2. **（关键一步）** 打开 `Timetable.ini`，滑到最底下，找到这行控制字体高亮放大的代码：`InlinePattern=^周. 课程表`
   将其改为：`InlinePattern=^周.`
   *(如果不改 ini，去掉文字后，周一的字就不会变黄变大了)*
