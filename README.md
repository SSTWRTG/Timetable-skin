# 🗓️ Timetable - Rainmeter 动态课表皮肤

这是一个使用 Rainmeter 和 Lua 脚本编写的桌面课表皮肤模板。它会自动判断今天是星期几，并在桌面上竖向显示当天的课程。

## ✨ 功能特点
- **自动切换**：根据电脑当前日期，自动读取并显示当天的课表。
- **竖向排版**：课程列表竖向排列，一目了然，不占用过多横向空间。
- **半透明背景**：自带圆角半透明背景板，不遮挡壁纸，美观大方。
- **高度自定义**：字体、字号、颜色、背景透明度和尺寸均可自由调整；支持自行修改上课天数（如改为单休或双休）。

---

## ⚠️ 重要提醒与避坑指南（使用前必看）

### 🔴 编码警告（最重要）
本皮肤依赖 Lua 脚本，Rainmeter 对脚本编码有严格要求：**Timetable.lua 必须保存为 UTF-16 LE 编码**（在 Windows 记事本“另存为”时，编码选择 **Unicode**）。
如果保存成了 UTF-8，皮肤会静默失效，桌面将什么都不会显示，且不易察觉。修改代码后请务必检查编码！

### 📂 找不到皮肤文件夹怎么办？
不同电脑的 Rainmeter 安装方式不同（标准安装、便携版或自定义路径），皮肤目录不一定在“文档”里。
**最稳妥的方法：**
右键点击系统托盘（右下角）的 Rainmeter 图标 -> 选择 **“皮肤”** -> **“打开皮肤目录”**。弹出的窗口就是当前电脑正确的皮肤文件夹。

### 📅 课程数量与背景板高度匹配
默认背景板高度 BgHeight=235 是按 **8 节课** 设计的。如果你在 Lua 里删减或增加了课程，文字高度会改变，但背景板不会自动缩放。
- 如果课变少了，背景板底部会留白，建议调小 BgHeight。
- 如果课变多了，文字会超出背景板，建议调大 BgHeight（每节课大约对应 22~26 像素）。

## 🚀 安装方法

1. 下载并解压本仓库的代码。
2. 右键托盘 Rainmeter 图标 -> 皮肤 -> 打开皮肤目录。
3. 将解压出的 Timetable 文件夹整个放入皮肤目录中（确保 Timetable.ini 和 Timetable.lua 在同一个文件夹里，不要多套子文件夹）。
4. 刷新 Rainmeter，在管理器中找到 Timetable，加载 Timetable.ini。

## 🛠️ 一、基础自定义（外观与内容）

### 1. 修改你的专属课表
用文本编辑器（如记事本或 VS Code）打开 Timetable.lua，找到最上方的 days 区域。每一行代表一天，课程之间用 \n 隔开。

修改示例：
days["周一"] = "第1节 语文\n第2节 数学\n第3节 英语\n第4节 自习"
days["周二"] = "第1节 物理\n第2节 化学\n第3节 体育"

（注意：\n 是换行符，保留它才能让课程竖向排列。修改后另存为 Unicode 编码。）

### 2. 修改外观样式
打开 Timetable.ini，找到 [Variables] 区域，以下参数可以自由调整：

| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| FontFace | Microsoft YaHei | 字体名称，需确保电脑已安装该字体 |
| FontSize | 14 | 课程列表的正文大小 |
| TitleSize | 18 | “周X 课程表”标题的大小 |
| FontColor | 255,255,255,255 | 正文颜色（RGBA格式，纯白） |
| AccentColor | 255,200,0,255 | 标题的强调色（金黄色） |
| BgWidth | 260 | 背景板的宽度（课程名过长折行时需调大） |
| BgHeight | 235 | 背景板的高度（根据课程数量自行微调） |
| BgAlpha | 160 | 背景板透明度（0 为全透明，255 为完全不透明） |

## 🧠 二、进阶逻辑自定义（修改 Lua 代码）

如果你懂一点点代码，可以修改 Timetable.lua 底部的 Update() 函数，实现更符合你学校作息的逻辑。

### 如何将上课时间改为“周一到周五”（周末双休）？
原版代码默认是周一到周六。如果你的学校周末没课，请按以下两步修改：

1. 在 Timetable.lua 中，找到 Update() 函数里的这句代码：
    if wd == 1 then
   将其改为：
    if wd == 1 or wd == 7 then
   （解释：在 Lua 中，1 代表周日，7 代表周六。修改后，周六和周日都会触发休息逻辑。）

2. 删掉上面 days 区域里的 days["周六"] = "..." 这一行代码。

### 如何修改休息日的文字提示？
在 Update() 函数里找到这句代码：
    return "周日 休息"
把引号里的文字改成你喜欢的即可，比如 return "今天没课，出去嗨！"。

### 如何去掉标题里的“课程表”三个字？
找到 Update() 函数里的这句代码：
    return day .. " 课程表\n" .. content
改成：
    return day .. "\n" .. content
